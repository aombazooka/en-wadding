# การ์ดแต่งงานออนไลน์ · แน็ป & อาย

เว็บการ์ดแต่งงานโทนชมพูหม่น มินิมอล — แตะเปิดซองการ์ด, รายละเอียดบ่าวสาว, แกลเลอรี, กำหนดการ, แผนที่,
ฟอร์มส่งคำอวยพรพร้อมแนบรูป และ QR พร้อมเพย์

## ไฟล์หลัก

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าการ์ด (เนื้อหา, รูป, QR แก้ในไฟล์นี้) |
| `wish.php` | รับคำอวยพร + รูปจากแขก บันทึกลง MySQL |
| `admin.php` | หน้าผู้ดูแล: ดูคำอวยพร/รูป, ค้นหา, ลบ, ดาวน์โหลด CSV |
| `includes/` | config, เชื่อมฐานข้อมูล, schema (เปิดผ่านเว็บไม่ได้) |
| `uploads/` | รูปที่แขกส่งมา (เปิดผ่านเว็บไม่ได้ ดูได้จาก admin เท่านั้น) |
| `assets/` | รูปประกอบ เช่น QR |

## ติดตั้ง

ต้องใช้ PHP 8+ (มี `fileinfo`, `mbstring`, `pdo_mysql`) และ MySQL/MariaDB

1. คัดลอก `includes/config.example.php` เป็น `includes/config.php`
2. แก้ค่าฐานข้อมูลและตั้ง `admin_password`
3. สร้างฐานข้อมูลตามชื่อใน config (บน XAMPP ระบบสร้างให้เองได้) — ตาราง `wishes` จะถูกสร้างอัตโนมัติ
4. ให้โฟลเดอร์ `uploads/` เขียนไฟล์ได้
5. เปิด `index.html` และ `admin.php`

ใส่ชื่อแขกในลิงก์ได้ เช่น `index.html?to=คุณสมชาย` — ซองการ์ดจะขึ้นว่า "เรียน คุณสมชาย"
